### Projeto em destaque

**[biblioteca-api](https://github.com/ViniciuSetorio/biblioteca-api)** — Sistema de gestão de biblioteca com arquitetura de microsserviços

- 6 serviços Node.js/Express com responsabilidade única e banco PostgreSQL próprio cada
- API Gateway com Facade Pattern + Retry automático (axios-retry) para tolerância a falhas
- Stack completa containerizada com Docker Compose — ambiente local idêntico à produção
- Deploy contínuo em Render.com e Railway · Frontend em Vercel · Documentação Swagger
